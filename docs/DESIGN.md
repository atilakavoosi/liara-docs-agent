# DESIGN.md — لیارایار

## چرا این سند مهمه

یکی از داورها صراحتاً گفته: اگه UI بوی «ساخته‌شده با AI» بده (چه از نظر
ظاهر چه از نظر رفتار)، امتیاز از دست می‌ره. سه کلیشه‌ی مشخص که باید ازشون
دوری بشه: (۱) پس‌زمینه‌ی کرم + serif پرکنتراست + تراکوتا، (۲) پس‌زمینه‌ی
تقریباً مشکی + یک نئون تک، (۳) چیدمان روزنامه‌ای بی‌گردی. راه‌حل این پروژه:
**به‌جای انتخاب یک پالت عمومی، پالت واقعی خود لیارا رو از CSS واقعی
کنسولشون (`console.liara.ir`) استخراج کردیم**، نه حدس زدیم. اگه یک داور
از خود لیارا این رو ببینه، باید حس «این محصول لیاراست» بده، نه «یک قالب
چت‌بات ژنریک با رنگ‌های تصادفی».

## منبع رنگ‌ها

از `console.liara.ir` (باندل CSS واقعی محصول، نه سایت مارکتینگ) استخراج شد:

| رنگ خام لیارا | نقش در محصول اصلی | دفعات دیده‌شده |
|---|---|---|
| `#87fcc4` | mint — رنگ امضای برند | ۱۴ |
| `#28c1f5` / `#96dbfa` / `#57c5f7` | آبی آسمانی — رنگ ثانویه | ۱۵ |
| `#23252d` / `#2d333b` / `#3e404e` | خاکستری-سرمه‌ای تیره (نه مشکی خالص) | پس‌زمینه‌ی دارک‌مود |
| `#ff4755` / `#fc2b3a` | قرمز خطا | استاتوس |
| `#98db7c` / `#7ac65c` | سبز موفقیت («وترملون-گرین» در کدشون) | استاتوس |

نکته‌ی مهم: `#87fcc4` خام روی پس‌زمینه‌ی سفید کنتراست کافی برای متن نداره
(خیلی روشنه). برای حالت روشن، یک سایه‌ی تیره‌تر از همون هیو ساخته شد
(`#0EA36F`) که هم به برند وفاداره هم WCAG-AA رو رعایت می‌کنه. رنگ خام
`#87fcc4` فقط در دارک‌مود (که روی پس‌زمینه‌ی تیره کنتراست عالی داره) و
به‌شکل fill/badge استفاده می‌شه.

## فونت

بررسی شد که خود لیارا از فونت تجاری «Yekan Bakh» استفاده می‌کنه، ولی
لایسنسش برای بازتوزیع روشن نیست (فایل‌های «رایگان» در سایت‌های فارسی
غیررسمی‌ن، نه از منبع رسمی). به‌جاش **Vazirmatn** انتخاب شد — چون:

- لایسنس SIL OFL، ۱۰۰٪ آزاد برای استفاده‌ی تجاری، بدون ریسک حقوقی
- Variable font با بازه‌ی وزن ۱۰۰ تا ۹۰۰، یعنی می‌شه با همین یک خانواده
  هم عنوان‌های سنگین ساخت هم متن ظریف — به‌جای قاطی کردن یک فونت
  انگلیسی برای «عنوان» با یک فونت فارسی برای «متن» (که معمولاً هارمونی
  بصری نداره و دقیقاً همون چیزیه که حس دست‌ساز/AI-generated می‌ده)
- در محصولات فارسی حرفه‌ای (دیوار، اسنپ، …) استاندارده — یعنی برای
  کاربر فارسی‌زبان آشنا و باکیفیت به‌نظر می‌رسه، نه عجیب

برای کد و رشته‌های فنی (نام فایل، کد خطا، JSON): **JetBrains Mono** —
خوانایی بالا برای کاراکترهای شبیه‌به‌هم (`0`/`O`، `1`/`l`) که در پیست
کردن دستورهای CLI و کدهای خطا حیاتیه.

## چیدمان

نه یک ستون حباب‌های چت (کلیشه‌ی «کپی ChatGPT»)، بلکه یک **کنسول پشتیبانی
دوستونه**:

- ستون اصلی: مکالمه، حداکثر عرض ~۷۶۰px برای خوانایی
- ستون کناری (دسکتاپ ≥۱۲۸۰px، شیت روی موبایل): **پنل شفافیت منابع** —
  هر سند بازیابی‌شده با یک نوار امتیاز نازک mint-پرشونده، عنوان، مسیر
  breadcrumb، و لینک واقعی به docs.liara.ir. این پنل عنصر امضای محصوله:
  کمتر کلونی از یک چت‌بات عمومی همچین شفافیتی درباره‌ی منبع جواب نشون
  می‌ده.
- پیام‌های دستیار به‌شکل بلوک محتوای جاری رندر می‌شن (بدون قاب حباب)،
  فقط پیام‌های کاربر حباب دارن — الگویی که در ابزارهای AI حرفه‌ای
  (نه دموهای اسباب‌بازی) دیده می‌شه.
- هر ابزار (۶ تا) UI اختصاصی خودش رو داره؛ هیچ‌کدوم JSON خام نشون
  نمی‌ده (جزئیات در کامنت کامپوننت‌ها).
- حالت خالی: به‌جای صفحه‌ی سفید، چهار سؤال پیشنهادی واقعی.
